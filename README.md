# Sales Prediction
## Overview
A machine learning project to predict product sales based on advertising expenditure across different channels.
## Objective
To analyze advertising data and build a regression model for predicting sales.
## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.
## Workflow
Data Cleaning → EDA → Feature Selection → Model Training → Evaluation → Prediction.
## Target
**Sales**
## Evaluation
MAE, MSE and R² Score.
